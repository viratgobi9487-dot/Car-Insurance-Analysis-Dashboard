# 🚗 Car Insurance Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing car insurance data and creating an interactive dashboard using Power BI.

The dashboard provides insights into policies, claims, customers, age groups, gender distribution, and other key insurance metrics.

## 🛠️ Tools & Technologies

* Power BI
* DAX
* Power Query
* Data Cleaning
* Data Transformation
* Data Visualization

## 🔍 Data Preparation & Cleaning

* Checked the dataset for duplicate records
* Checked for missing and null values
* Verified and corrected data types
* Checked data consistency and accuracy
* Created additional columns required for analysis

## 🧮 Data Transformation & DAX

* Created an **Age** column from the Date of Birth (DOB)
* Calculated customer age using the current date with DAX
* Created an **Age Category** column for age-group analysis
* Created DAX measures for key business KPIs
* Calculated **Total Policies**
* Calculated **Total Claim Amount**
* Created other required KPI measures
* Used `CALCULATE()` to separately analyze Male and Female customers

## 📊 Dashboard Features

* Total Policy KPI
* Total Claim Amount KPI
* Gender-wise Customer Analysis
* Age Category Analysis
* Policy and Claim Analysis
* Interactive filters and slicers
* Interactive charts and visualizations

## 📈 Key Insights

* Analyzed customer distribution by gender
* Analyzed customers across different age categories
* Examined total policies and claim amounts
* Identified patterns and trends in car insurance data

## 🎯 Project Objective

The main objective of this project is to transform raw car insurance data into meaningful insights through data cleaning, DAX calculations, and interactive Power BI visualizations.
